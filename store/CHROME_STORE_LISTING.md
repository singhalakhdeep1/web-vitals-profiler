## Name
Web Vitals Profiler

## Short Description (132 chars max)
Real-time Core Web Vitals monitoring with DevTools panel, live charts, regression detection, and export reports.

## Detailed Description
Web Vitals Profiler is a production-grade Chrome extension for developers who care about performance.

**Features:**
- Real-time monitoring of LCP, CLS, INP, FCP, TTFB, and TBT
- Custom DevTools panel with live charts and timeline
- On-page floating overlay for instant vitals feedback
- IndexedDB historical storage with trend analysis
- Automated performance regression detection
- Export reports as JSON, CSV, or HTML
- Slack webhook integration for team notifications
- 100% local — your data never leaves your device

Built with Manifest V3, React, TypeScript, and the web-vitals library.

## Category

## Privacy Policy
All performance data is stored locally on the user's device using IndexedDB and chrome.storage. No data is transmitted to external servers except when the user explicitly configures a Slack webhook URL.
